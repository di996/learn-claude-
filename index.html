Learn Claude Code the practical way

Claude Code is an AI coding assistant that runs in your terminal. You describe what you want in plain English – "add a dark mode toggle", "why is this test failing?" – and it reads your files, proposes edits, runs commands and explains what it did. It's one of the fastest ways to build software today, but only once you know how to drive it.

That's where most people get stuck. The tool itself is simple to install, but the workflow is new: when should you let it edit without asking? What is a CLAUDE.md file? How do you stop it when it heads the wrong way? Why do answers get worse in long conversations? These are the things that separate someone who "tried it once" from someone who ships with it every day.

Practice in a safe, simulated terminal

Every AgentDrills lesson runs in a simulation of a Claude Code session, right in your browser. There's nothing to install and nothing can break. You can approve the scary rm -rf command just to see what happens – nothing gets deleted. You can mistype a slash command and get a friendly nudge instead of an error. Because the simulation is scripted, it needs no API key and burns no tokens.

Who is it for?

  • Developers who want to get productive with Claude Code in an afternoon instead of a month of trial and error.
  • Product managers, designers and founders who want to build prototypes themselves and need a gentle start in the terminal.
  • Students and career switchers who want to put "AI-assisted development" on their CV – and actually mean it.
  • Teams rolling out Claude Code who want everyone on the same baseline before the first real project.

What makes it stick

Each lesson is built around repetition and immediate feedback – the same idea that makes language apps work. You see a short instruction, do it, and get feedback in under a second. Small wins add up to XP, daily streaks keep you coming back, and stars reward you for finishing without hints. By the end of the first unit you'll have launched sessions, reviewed diffs, managed permissions and created a CLAUDE.md file – muscle memory you'll use on day one of a real project.

From basics to power-user habits

The first lessons cover the essentials: starting a session in the right folder, asking good questions, approving or rejecting edits and commands, and the slash commands you'll use every day. Later lessons go further: pointing Claude at exact files with @, running shell commands with !, switching modes with Shift+Tab, letting Claude plan before it codes, interrupting with Esc, compacting long conversations and resuming yesterday's session with claude --continue.
