Getting Started

How to install Claude Code (even if you've never used a terminal)

You install Claude Code by pasting one command into your computer's terminal, then typing claude and signing in. It only takes a few minutes, and this guide walks you through every click.

AgentDrills team · Updated November 23, 2026 · 9 min read

Here's the short version. On a Mac or Linux computer, you open the Terminal app and paste curl -fsSL https://claude.ai/install.sh | bash. On Windows, you open PowerShell and paste irm https://claude.ai/install.ps1 | iex. Then you type claude, a browser window opens, and you sign in with your Claude account. Done.

If that paragraph sounded like a foreign language, don't worry. That's exactly who this guide is for. We'll go slowly, explain every new word, and tell you what you should see at each step, so you always know whether things are going well.

What you need before you start

Let's check three things first. It's much nicer to find a problem now than halfway through.

1. A computer that's new enough

Claude Code runs on:

  • Mac: macOS 13 (Ventura) or newer
  • Windows: Windows 10 (version 1809) or newer
  • Linux: for example Ubuntu 20.04 or newer, or Debian 10 or newer

You'll also want at least 4 GB of memory (RAM) and an internet connection. Almost any computer from the last few years is fine.

2. A paid Claude plan

This is the one that surprises people. The free Claude plan doesn't include Claude Code. You need a paid plan.

  • Pro, Max and Ultra are the personal plans you can buy on claude.com.
  • Team and Enterprise are plans a company buys for its staff.
  • Claude Console is the developer account, where you pay in advance with credits.

If you already pay for Claude to chat with it, you most likely have everything you need.

3. A supported country

Claude Code is only available in the countries Anthropic supports. If you can use Claude where you live, you're almost certainly fine.

No Node.js needed. Node.js is a tool for running JavaScript programs. Older guides online tell you to install it first. With the recommended installer, you don't need it anymore.

What a terminal is, and how to open one

A terminal is a window where you control your computer by typing instead of clicking. You type a command (a short instruction, like "install this" or "go into that folder"), press Enter, and the computer does it and prints a reply. Every Mac, Windows and Linux computer already has one built in.

It looks plain, usually just a dark or white window with a blinking cursor. That's normal. Nothing is broken.

On a Mac

Press Cmd+Space to open Spotlight (the Mac's built-in search bar), type Terminal and press Enter.

On Windows

Press Win+X and choose Windows PowerShell or Terminal from the menu. Windows actually has two kinds of terminal: PowerShell, the modern one, and an older one called CMD (Command Prompt). Both are just windows where you type commands, but they understand slightly different commands. You can tell them apart by the text at the start of the line:

PS C:\Users\YourName>     ← PowerShell (this is the one you want)
C:\Users\YourName>        ← CMD

On Linux

On most versions of Linux, press Ctrl+Alt+T, or search for "Terminal" in your app menu.

Pasting into a terminal

You don't need to type the install commands by hand. Copy them from this page and paste. One small trap: the paste shortcut isn't always the usual one.

  • Mac: Cmd+V
  • Windows PowerShell: Ctrl+V, or right-click
  • Linux: Ctrl+Shift+V

Install on a Mac or Linux

Open your terminal, paste this line and press Enter:

curl -fsSL https://claude.ai/install.sh | bash

In plain words, this says: "download Anthropic's install script and run it". curl is the part that downloads. A script is a small list of commands that runs one after the other. bash at the end is the program that runs it. The installer puts Claude Code in a folder inside your own user account.

Now the slightly nerve-racking part: for a little while, it may look like nothing is happening. The installer doesn't show a progress bar while it downloads. Leave the window open and wait. When you get a fresh line with a blinking cursor again, it's finished.

Already use Homebrew? Homebrew is a popular package manager for Mac: a kind of app store you use from the terminal. If you have it, brew install --cask claude-code also works. Just know that the Homebrew version doesn't update itself. If you've never heard of Homebrew, ignore this box and use the command above.

Install on Windows

Open PowerShell (see above), paste this line and press Enter:

irm https://claude.ai/install.ps1 | iex

Again, give it a minute and wait for the blinking cursor to come back. You don't need administrator rights (the special permission to change settings for everyone on the computer).

If you ended up in CMD instead of PowerShell, that's fine too. CMD has its own version of the command:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Two extra words Windows users will meet

  • Git for Windows is a free program. It includes Git Bash, a terminal like the ones on Mac and Linux. Claude Code works without it and uses PowerShell instead. Still, installing it is recommended, so Claude can use its usual tools. You'll want Git sooner or later anyway. It's how most people save versions of their code.
  • WSL (Windows Subsystem for Linux) lets you run Linux inside Windows. Some developers prefer it. If you use WSL, open your WSL terminal and follow the Mac and Linux steps instead. If you don't know what WSL is, you don't need it.

Check that it worked

Close your terminal and open a new one. This matters: a terminal that was already open sometimes doesn't "see" newly installed programs until you restart it. Then type:

claude --version

If everything went well, you'll see a version number followed by "(Claude Code)", something like 2.1.211 (Claude Code). Your number will be different, and that's fine. Any version number means Claude Code is installed.

Want a fuller check-up? Run this:

claude doctor

It looks over your installation and settings and tells you if something needs fixing. It only reads and reports, so it's safe to run any time.

Sign in the first time

Claude Code always works inside a folder on your computer, and it can read and change the files in that folder. So first, move into a project folder with the cd command ("change directory"). Say you have a folder called my-project:

cd my-project
claude

The first time you run claude, it opens a browser window and asks you to log in. Use the same account you use for Claude (or your Console account, if that's what you have). Here's what can happen next:

  • The browser opens, you sign in, and it sends you back. Perfect. The terminal says Login successful. Press Enter to continue.
  • The browser doesn't open by itself. Press c in the terminal. That copies the login link, which you can paste into your browser.
  • The browser shows you a code instead of sending you back. Copy it, go back to the terminal, and paste it where it says Paste code here if prompted.

You only do this once. Claude Code remembers your login. If you ever want to switch to a different account, type /login while Claude Code is running. Words that start with a slash, like /login, are commands for Claude Code itself rather than messages to Claude.

When something goes wrong

Most install problems are one of a handful of classics. Here's what they look like and what to do.

"command not found" or "not recognized"

You type claude and get something like zsh: command not found: claude on a Mac or The term 'claude' is not recognized on Windows. First, close the terminal and open a brand-new one. That fixes it surprisingly often.

If it still happens, your computer doesn't know where Claude Code was installed. Your terminal only looks for programs in certain folders. That list of folders is called the PATH. The installer's folder isn't on it yet. Anthropic's troubleshooting page has the exact commands to add it for each system. Run them, open a new terminal and try again.

Windows: "'irm' is not recognized" or "'&&' is not a valid statement separator"

You pasted a command into the wrong kind of terminal. The first message means you're in CMD with the PowerShell command. The second means you're in PowerShell with the CMD command. Check the start of the line (PS C:\ or C:\) and use the matching command.

Windows: "does not support 32-bit Windows"

"32-bit" is an older type of program. You probably opened the old version of PowerShell, called Windows PowerShell (x86). The "(x86)" in the name gives it away. Close it and open the one without "(x86)".

Mac: an error that mentions "Mac OS X 13.0"

Your macOS is older than version 13. Update it through Software Update, then install again.

Not sure what's wrong? Run claude doctor and read what it says. It usually points straight at the problem.

Keeping Claude Code up to date

Good news: if you used the recommended installer, Claude Code updates itself in the background. New versions take effect the next time you start it. You don't have to do anything.

If you ever want to update right now, type:

claude update

It either installs the newest version or tells you you're already up to date. Did you install with Homebrew or another package manager (an app store for the terminal)? Those versions don't update on their own. Upgrade them through that tool instead.

What to do next

You've installed Claude Code, checked it, and signed in. That's honestly the hardest part for most beginners, because everything after this happens in plain English.

Your next step is your first real session: starting Claude in the right folder, asking about the project before you ask for changes, and reading the little ⏺ lines that show what Claude is doing. Our guide to your first Claude Code session covers all of that.

Or, if you'd rather learn by doing, practice it first in a safe, simulated terminal. You'll type the same commands you just read about, and get hints when you make a mistake.
